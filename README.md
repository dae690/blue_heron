# 🐦 **Extracting Relevant Records from Two Large Colonial Waterbird Datasets**

🔬 A Conservation Data Analytics Project using Historical Bird Survey Data from the Atlantic Flyway

## 📘 **Project Overview**
This project is part of DAEN 690: Data Analytics Project at George Mason University. Our objective is to extract, clean, validate, and visualize historical survey data of colonial waterbirds (CWBs) across the Atlantic Flyway to support science-driven conservation planning.

---

## 👥 **Client Profile**
Atlantic Flyway Council (AFC) – Nongame Migratory Bird Technical Section (NMBTS)

🐦 Focus: Monitoring and conserving bird populations in the Atlantic Flyway

🎯 Goal: Support conservation decision-making through reliable historical data extraction

## 🧠 Project Objectives
✅ Extract reliable records from 2 large datasets of colonial waterbirds

✅ Standardize taxonomy using AOU codes and update deprecated identifiers

✅ Remove duplicates, clean inconsistencies, and validate location coordinates

✅ Deliver interactive dashboards for stakeholders to explore colony distribution and trends

✅ Enable informed conservation strategies through accessible visual tools


---


## 📌 **Abstract**  
Monitoring colonial waterbirds across the Atlantic Flyway provides critical insight into ecosystem health. This project involved cleaning and standardizing historical survey data, updating species codes, and developing visualizations to support regional conservation planning. ## 🧩 **Project Structure**  
- **scripts/**: Python code for cleaning, updating AOU codes, and validation.  
- **data/**: Raw and cleaned datasets, along with reference files.  
- **tableau/**: Dashboards developed for species visualization and trend analysis.  
- **docs/**: Methodology and findings.

## 🌿 Why This Project Matters
Colonial waterbirds are ecological indicators of wetland and coastal health. By cleaning and standardizing decades of observational data, this project contributes directly to improving data-driven conservation in one of North America's most vital flyways.
